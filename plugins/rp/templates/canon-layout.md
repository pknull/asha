# Canon Layout

**Copy this file to `Memory/canon-layout.md` and edit the paths to match your project.**

This is the *nouns* half of the RP plugin's contract. The plugin ships the verbs — session lifecycle, the continuity gate, ratification — and reads this register to find out where *your* canon lives. Nothing in the plugin should hardcode a path that appears in this table.

## Why this exists

RP agents previously addressed one project's directory tree directly (`Lore/World/Characters/`, `Lore/World/Magic/Artefacts/`, …). That layout is one vault's convention, not a universal one. Hardcoding it meant the agents silently resolved nothing in any other project — lookups returned empty, and "no canon found" was indistinguishable from "no canon exists". Routing every path through this register makes the same plugin correct in a project that keeps canon under `docs/setting/`, `wiki/`, or anywhere else.

## Entity paths

Globs are project-relative. Multiple globs per kind are allowed — list them comma-separated, searched in order. Delete rows your project has no concept of; add rows it needs.

| Kind | Path glob(s) | Notes |
|---|---|---|
| `character` | `Lore/World/Characters/*.md` | NPCs and profiled cast |
| `pc` | `Lore/TTRPG/RP Assets/Characters/*.md` | player-facing character sheets |
| `location` | `Lore/World/Places/**/*.md` | |
| `artifact` | `Lore/World/Magic/Artefacts/*.md` | |
| `faction` | `Lore/World/Factions/*.md` | |
| `magic` | `Lore/World/Magic/*.md`, `Lore/World/Magic/Spheres/*.md` | systems and effects |
| `session_record` | `Work/rp/rp_session_*.md` | raw session logs (plugin-owned, rarely changed) |
| `session_curated` | `Lore/TTRPG/Notes/*.md` | promoted / edited session write-ups |

> The values above are the **historical default**, preserved so existing projects keep working without edits. They are not a recommendation — a new project should replace them wholesale.

## Source registers

| Register | Path | Role |
|---|---|---|
| `priced_stakes` | `Lore/TTRPG/canon-sources.md` | maps a stake (escape, resurrection, a bargain) → the file and section that prices it. Consulted before adjudicating anything irreversible. |
| `invariants` | `Memory/invariants.md` | the compiled projection the per-turn continuity gate reads. Generated by `/rp:extract-invariants` — never authored by hand. |

## Resolution contract

Agents that resolve canon MUST:

1. Read `Memory/canon-layout.md` if it exists and use its globs.
2. Fall back to the defaults in this template when it does not.
3. **Report which globs were searched** when a lookup returns nothing. A negative canon result without a searched-paths list is not a finding — it is an unchecked guess, and it is indistinguishable from a misconfigured layout.
4. Never invent a path that is not in the register. If a needed kind has no row, say so and ask.

## Promotion targets

`/rp:end` promotes ratified canon into these same paths — the register is the single source of truth for both reading and writing, so a project that moves its canon only edits one file.
